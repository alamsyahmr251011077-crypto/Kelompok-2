# Paket Serial dan Data (Klara Airelin Kele)

| Paket | Alasan untuk pengembang IoT |
|---|---|
| minicom | Terminal serial untuk berkomunikasi dengan mikrokontroler (ESP32, Arduino) |
| picocom | Alternatif terminal serial yang ringan |
| jq | Mengolah data JSON dari sensor dan pesan MQTT |
| sqlite3 | Penyimpanan data sensor lokal tanpa server database |
| curl | Menguji API HTTP dan mengunduh data dari perangkat |
