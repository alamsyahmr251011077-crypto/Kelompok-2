DAFTAR PAKET YANG DIHAPUS DARI NEXUS (DISTRO PENGEMBANG IOT)
Distro induk: Xubuntu 24.04.3. Skrip: tahap1/scripts/02-remove.sh

Prinsip pemilihan: paket dihapus jika tidak dibutuhkan pengembang IoT
(perangkat lunak perkantoran, multimedia, hiburan, perangkat optik) atau
tidak sesuai target pengguna, sehingga ISO lebih kecil dan RAM lebih hemat.

| Paket | Perkiraan ukuran terpasang | Alasan dihapus |
|---|---|---|
| libreoffice* (core, common, writer, calc, dll.) | sekitar 300 MB | Paket perkantoran, sangat besar, tidak berkaitan dengan pengembangan IoT. Dokumen cukup dibuka dengan editor teks. |
| gimp* | sekitar 85 MB+ | Editor gambar, besar. Pengembang IoT tidak membutuhkannya. |
| rhythmbox* | kecil-sedang | Pemutar musik, tidak relevan untuk lingkungan pengembangan. |
| simple-scan | kecil | Aplikasi pemindai dokumen, tidak ada kebutuhan pemindai pada target pengguna. |
| xfburn | kecil | Pembakar CD/DVD. Media optik jarang dipakai, distribusi lewat USB atau jaringan. |
| hexchat* (beserta plugin lua, perl, python3) | sekitar 1 MB | Klien chat IRC, tidak relevan untuk pengembangan IoT. |
| fonts-noto-cjk | sekitar 89 MB | Font Tiongkok/Jepang/Korea. Target pengguna memakai bahasa Indonesia dan Inggris. |
| xubuntu-docs | sekitar 76 MB | Dokumentasi bantuan Xubuntu, informasi tersedia online. |

Paket yang sengaja TIDAK dihapus:
- linux-firmware: dibutuhkan agar Wi-Fi dan perangkat keras lain berfungsi.
- snapd, firefox, thunderbird: Firefox dan Thunderbird berupa paket snap.
- xfce4-session, xfwm4, lightdm, thunar: komponen inti desktop.
- gcc/g++: dibutuhkan build-essential (paket Orang 4) untuk kompilasi program IoT.

Catatan: 'apt autoremove' sengaja tidak dijalankan karena berisiko ikut
menghapus komponen desktop XFCE.
