# Paket Pemrograman (MUHAMMAD REIHAN)

| Paket | Alasan untuk pengembang IoT |
|---|---|
| python3 | Bahasa utama untuk skrip sensor, prototipe, dan klien MQTT |
| python3-pip | Memasang pustaka Python (misalnya paho-mqtt) |
| python3-venv | Membuat lingkungan virtual, wajib di Ubuntu 24.04 karena pip global dibatasi |
| build-essential | Kompilator gcc, g++, dan make untuk program C/C++ perangkat |
| git | Kontrol versi proyek IoT |
